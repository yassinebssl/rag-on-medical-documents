\begin{frame}{What runs today}
  \begin{itemize}
    \item 50 documents ingested: 1530 records $\to$ 3410 chunks in Chroma
    \item Hybrid retrieval: BGE-M3 + our own BM25, fused by RRF, top 5
    \item Refusal gate: MiniLM cross-encoder, threshold 0.5
    \item Free LLM answers from passages [1]--[5]; citations are checked
    \item Gradio app; 113 automated tests pass
  \end{itemize}
  \vfill
  \small The pipeline and the app were complete on 15 November. Since then: the LLM evaluation, at 50 free requests a day.
  \note{Speaker: Boussoualim Yassine. Same architecture as the Checkpoint 1 slide, nothing planned is missing. The Git history shows the dates. The work since Checkpoint 1 is the evaluation run, the error analysis and the documents.}
